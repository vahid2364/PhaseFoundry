# PhaseFoundry

<p class="pf-tagline">A CALPHAD-coupled phase-field modeling toolkit that goes straight from a thermodynamic database to spinodal decomposition microstructures — binary, ternary, or quaternary, with no code changes required.</p>

`PhaseFoundry` connects thermodynamic databases generated by [PhaseForge](https://github.com/dogusariturk/PhaseForge) directly to a pseudo-spectral Cahn-Hilliard solver, evaluating exact chemical potentials and Gibbs energy Hessians via analytic Jansson derivatives in `pycalphad`, and optionally coupling coherency strain through a spectral micromechanics solver with MLIP-derived, composition-dependent elastic constants. The result is a quantitative, end-to-end pipeline from a CALPHAD TDB to spinodal decomposition microstructures in multicomponent alloys — driven by real thermodynamics, not hand-fitted surrogates.

<figure class="pf-figure" markdown>
![Elasto-chemical spinodal decomposition in Nb-Hf-V](images/tutorial_2d_ternary_elastic/03_interconnected_spinodal_t5000s.png)
<figcaption markdown>**Real simulation output** — coherency-strain-coupled spinodal decomposition in Nb-Hf-V at 500 °C (x_Nb = 0.50, x_Hf = 0.25, x_V = 0.25), 128×128 2D Cahn-Hilliard run, t = 5000 s. This bicontinuous pattern goes on to coarsen into elongated, diagonally-oriented rafts driven by the cubic elastic anisotropy computed from MLIP-derived elastic constants in Step 1b — see the [ternary tutorial](tutorial_2d_ternary_elastic.md) for the full walkthrough.</figcaption>
</figure>

## Pipeline

<div class="pf-pipeline">
  <div class="pf-step"><strong>Step 1</strong>pycalphad → HDF5 thermodynamic tables (G_m, μ, ∂μ/∂x)</div>
  <div class="pf-step pf-step--optional"><strong>Step 1b·1c·1d</strong>elastic constants · tie-lines · phase map (optional)</div>
  <div class="pf-step"><strong>Step 2</strong>surrogate fit + spinodal/binodal boundaries</div>
  <div class="pf-step"><strong>Step 3</strong>Cahn-Hilliard PFM simulation (pseudo-spectral)</div>
  <div class="pf-step"><strong>Step 4</strong>post-processing + field extraction</div>
  <div class="pf-step pf-step--optional"><strong>Step 5·6</strong>validation · chemical vs. elasto-chemical comparison (optional)</div>

## Features

<div class="grid cards" markdown>

-   :material-chart-scatter-plot:{ .lg .middle } **Spinodal stability analysis**

    ---

    Gauge-invariant eigenvalues and eigenvectors of the chemical and coherent Gibbs energy Hessian.

-   :material-function-variant:{ .lg .middle } **Exact Jansson derivatives**

    ---

    Chemical potentials evaluated directly from CALPHAD datasets — no finite-difference approximation.

-   :material-chart-line-variant:{ .lg .middle } **Semi-implicit spectral solver**

    ---

    Pseudo-spectral Cahn-Hilliard integration with Eyre convex-splitting stabilization (per-component A_i).

-   :material-cube-scan:{ .lg .middle } **Elasto-chemical coupling**

    ---

    Composition-dependent eigenstrain through a Moulinec-Suquet spectral micromechanics solver.

-   :material-atom-variant:{ .lg .middle } **SQS/MLIP elastic constants**

    ---

    Interpolated across quaternary composition space — ORB-v2, GRACE-2L, and other MLIPs.

-   :material-chart-multiple:{ .lg .middle } **Multiple surrogate backends**

    ---

    CT2D, two-stage RBF→RGI, pure RBF; regular grid, Sobol, or Dirichlet composition sampling.

-   :material-console-line:{ .lg .middle } **`pf-*` console-script CLI**

    ---

    `pf-generate`, `pf-simulate`, `pf-validate`, ... alongside direct `python workflows/.../run.py` calls.

-   :material-clipboard-text-clock-outline:{ .lg .middle } **Structured run logging**

    ---

    Opt-in timing records, config/TDB fingerprinting, peak-memory tracking, free-energy monotonicity checks.

-   :material-image-multiple-outline:{ .lg .middle } **STEM-style figures**

    ---

    Main panel + per-element insets, generated directly from simulation output.

-   :material-cogs:{ .lg .middle } **Config-driven pipeline**

    ---

    Binary, ternary, and quaternary systems — no code changes required, ever.

-   :material-speedometer:{ .lg .middle } **Optional GPU acceleration**

    ---

    CuPy backend with incremental NPZ checkpointing for long runs.

-   :material-vector-polyline:{ .lg .middle } **High-dimensional visualization**

    ---

    Affine projection of spinodal regions in composition spaces beyond 3D.

</div>
